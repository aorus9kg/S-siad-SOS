# S-siad-SOS
Polityka Prywatności i Usunięcie Konta – Sąsiad SOS.

1. Polityka Prywatności
Aplikacja Sąsiad SOS przetwarza dane użytkowników (takie jak adres e-mail, dane profilu oraz lokalizacja) w celu świadczenia usług łączących zleceniodawców z wykonawcami. Dane są szyfrowane i zabezpieczone. Nie udostępniamy danych osobom trzecim bez potrzeby.
